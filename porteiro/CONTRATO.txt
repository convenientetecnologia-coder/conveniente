   Passo B — fecha o PowerShell, abre de novo (Git no PATH), cola ISTO:

     cd \
     if (Test-Path "C:\conveniente") { Remove-Item -Path "C:\conveniente" -Recurse -Force }
     git clone https://github.com/convenientetecnologia-coder/conveniente.git "C:\conveniente"
     cd C:\conveniente
     npm install
     powershell -NoProfile -ExecutionPolicy Bypass -File C:\conveniente\instalar_porteiro.ps1

   C:\auto_vigia SOBREVIVE ao Remove-Item de C:\conveniente.

   reinicia o PC, limpa lixeira, e o Conveniente sobe sozinho (AUTO_BOOT).
   StandbyList comeca no index, nao no porteiro.
