## Correção aplicada (código)

- **Servidor** (`/api/perfis/close-all`):
  - Passo atômico: seta `desired.active=false` (e `virtus:'off'`) para todos.
  - Cancela `_openAll` se estiver ativo.
  - Fecha sequencialmente com retry (deactivate/hard-close).
