### Checkups (relatórios)

Esta pasta guarda **relatórios detalhados** de investigação/auditoria.

Regras:

- Sempre criar um arquivo novo por checkup (não sobrescrever histórico).
- Nome sugerido: `checkup_YYYY-MM-DD_assunto.md` (ex.: `checkup_2026-01-29_locks_e_timeouts.md`).
- Usar o template: `docs/checkups/TEMPLATE_CHECKUP.md`.
- Registrar um **resumo de 1–3 linhas** na `docs/TIMELINE.md` apontando para o arquivo do checkup.
