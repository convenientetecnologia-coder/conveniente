# INC-20260201-0000-01 — Groq config: garantir auto-download + auto-correção de modelo em TODOS os hosts após update/restart

**P**: P1  
**Sistema**: conveniente + sitechatbot (CT)  
**State**: `in_progress`  
**Rollout**: `needs_restart`  
**Validation**: `not_run`  

---

## Pedido (humano)

- Ao instalar/atualizar a versão em todos os servidores, ao iniciar o serviço, precisa ser **110% garantido** que cada host vai “baixar automaticamente” o `groq_config.json` com o **modelo correto** e **API key correta** (sem intervenção manual por host).

> Nota de segurança: **não registrar secrets** em docs/logs. A chave fica somente no `ct.env` do CT e é enviada via comando `set_groq_config`.

---

## Como deveria ser (contrato)

1) Host `conveniente` sobe (boot) e faz `/report` imediatamente.  
2) Se faltar config OU o modelo estiver divergente do modelo esperado, o host sinaliza `needsGroqConfig=true`.  
3) CT enfileira `set_groq_config` para o host (idempotente / dedupe).  
4) Host persiste em `C:\conveniente\dados\groq_config.json` e no próximo `/report` aparece `needsGroqConfig=false`.  

---

## Mudança implementada (mudança mínima)

- Host (`conveniente/scripts/dashboard.js`) agora considera `needsGroqConfig` quando:
  - API key ausente, ou
  - modelo ausente, ou
  - **modelo efetivo divergente do modelo esperado** (default global no código, sobrescritível por env).
- Telemetria segura no `/report`: `payload.groq` com `expectedModel`, `effectiveModel`, `effectiveSource`, `effectiveApiKeyPresent`, `fileUpdatedAt` (sem segredo).

Arquivos:
- `C:\conveniente\scripts\groqConfig.js` (`readGroqConfigMeta`)
- `C:\conveniente\scripts\dashboard.js` (campo `payload.groq` + regra `needsGroqConfig`)

---

## Evidência a coletar (GPT via CT)

- `/servers` (snapshots) mostrando `needsGroqConfig` e os campos `groq.*` por host.
- `commands.log` + ACK do `set_groq_config` por host.

---

## Validação (critério de sucesso)

- Após `self_update` + restart `node index.js` em um host sem `groq_config.json`:
  - o host pede config (`needsGroqConfig=1`) e recebe `set_groq_config`,
  - o arquivo é criado,
  - em até 1–2 ticks o host para de pedir (`needsGroqConfig=0`),
  - e `groq.effectiveModel` == `groq.expectedModel`.
