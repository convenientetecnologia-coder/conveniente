## 5) Codigo auditado (causa tecnica provavel)

```txt

  ... reason: 'missing_meta_message_id' ...
  dispatch_ct: false,
  queue_mode: 'capture_only',
  flow_stage: 'missing_meta_message_id_sync_only',
  continue;
}
```

Quando `__deltaIsMetaIdAlreadyOnDisk(dedupMetaId)` retorna true, o frame tambem e desviado para `capture_only`:

```txt
  dispatch_ct: false,
  queue_mode: 'capture_only',

```
