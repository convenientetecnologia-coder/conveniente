## Sintoma (humano)

No **Sistema Interno → Visão geral → Resumo**, os KPIs não batem com as abas:

- Ex.: **Ativos** no Resumo ≠ **Ativos** na aba Ativos (ex.: 306 vs 310).
- Ex.: **Teste** no Resumo ≠ “quantidade real” nas abas de teste.

## Como deveria ser (humano)

- KPIs do Resumo devem ser **a mesma fonte de verdade** das abas (sem divergência).

---

## Evidência runtime (SQLite do CT)

Coleta feita localmente no CT via Node (sem UI, direto no DB):

- DB: `C:\sitechatbot\dados\convenientetecnologia.sqlite`
- Query drivers: `SELECT status, count(1) FROM ct_drivers GROUP BY status`
- Query memberships: `SELECT status, count(1) FROM ct_driver_memberships GROUP BY status`

Resultado observado:
- `ct_drivers.active = 306` e `ct_driver_memberships.active = 310`
- `ct_drivers.test = 10` e `ct_driver_memberships.test = 11`

Também foi confirmado:
- `/convenientetecnologia/api/tests?bucket=running` → 6
- `/convenientetecnologia/api/tests?bucket=ended` → 5
- Total esperado de “test” (participações) = 6 + 5 = 11 (bate com memberships.test=11)

---

## Root-cause (prova por código)

O endpoint do Resumo (`/convenientetecnologia/api/dashboard`) vinha de:

- `C:\sitechatbot\convenientetecnologia\lib\ctStore.js` → `getDashboard()`:
  - KPI era calculado com `ct_drivers` (cadastros globais).

Enquanto as abas (Ativos/Testes/Reprovados/Removidos/Banidos) usam:

- `C:\sitechatbot\convenientetecnologia\public\ct.js` → `apiGetAllMemberships(...)` / `/api/memberships?status=...`
  - Dados vêm de `ct_driver_memberships` (participações por cidade/grupo).

Logo: **duas fontes diferentes** → divergência inevitável.

---

## Fix (mudança mínima, sem quebrar)

### Backend

- `ctStore.getDashboard()` agora:
  - mantém `kpi.total` = total de **cadastros** (`ct_drivers`) para não confundir “base completa”
  - muda `kpi.by_status` para vir de **participações** (`ct_driver_memberships`) para sincronizar com as abas
  - adiciona `kpi.memberships_total` (total de participações) para telemetria

### Frontend

- `Visão geral → Resumo`:
  - rótulo “Total” virou **“Cadastros”**
  - rótulo “Teste” virou **“Testes (total)”** (rodando + encerrados)
