## Sintomas / Pedido (humano)

- O “Invocar Humano” abre um mini painel no navegador com botões (retomar, copiar login/senha etc).
- Quer adicionar no painel:
  - **Fechar navegador**
  - **Pausar Robe 24h**
  - **Excluir conta** (mesmo comportamento de “excluir conta” atual: fecha navegador + remove local + envia pro estoque “excluídas”)
- Quer confirmação técnica de que **quando está em modo humano invocado**, o sistema **não trabalha naquele navegador**.

---

## Base técnica (o que existe hoje)

- O painel (HUD) é construído em `C:\conveniente\scripts\worker.js` no bloco **Human Overlay (HUD)**.
  - Ele usa `page.exposeFunction(...)` para executar ações no Node sem depender de HTTP/CORS.
- `Invocar Humano` pode acontecer:
  - automaticamente em **captcha/checkpoint** (política atual), e/ou
  - manualmente via botão (rota `/api/perfis/:nome/invoke-human` → worker handler `invoke_human`).

---

## Decisões de alinhamento (confirmadas)

1) **Fechar navegador no HUD**: opção **B** — **fecha, mas permite reabrir depois** (não força `desired.active=false`).
2) **Robe 24h no HUD**: **somente** setar cooldown do Robe para 24h; não fecha, não mexe em `humanHold/humanControl`, não retoma automação.
3) **Excluir conta no HUD**: com **dupla confirmação forte** (`confirm` + digitar `EXCLUIR`).

---

## Implementação (prescrição técnica) — aplicada no código

Arquivo:
- `C:\conveniente\scripts\worker.js`

### Mudanças no HUD

- Adicionados botões:
  - **Robe 24h**
  - **Fechar navegador**
  - **Excluir conta**
  - Renomeado o botão antigo “Fechar” para **“Ocultar painel”** (evita confusão com “Fechar navegador”).

### Ações (Node-side) e garantias

- **Robe 24h**
  - Atualiza `manifest.robeCooldownUntil = now + 24h` e `robePauseReason='manual'`.
  - Não altera `humanHold/humanControl`, não fecha navegador, não retoma automação.

- **Fechar navegador**
  - Chama o motor canônico do sistema: `handlers.deactivate({ reason:'human_overlay_close', policy:'preserveDesired' })`.
  - Não força `desired.active=false` (permite reabrir depois, conforme política/desired/nurse).

- **Excluir conta**
  - Dupla confirmação no HUD.
  - Executa o fluxo canônico: `DELETE /api/perfis/:nome` via localhost, garantindo:
    - fechar se ativo,
    - purge local,
    - envio ao CT “estoque excluídas” (com queue/fallback já existente).

### Logs (enterprise)

Registra em `provision_audit.jsonl`:
- `human_overlay_action_begin`
- `human_overlay_action_done`
- além de `human_overlay_ui_event` para cliques do HUD.

---

## Garantia: “robô não mexe no navegador humano”

- Ao entrar em modo humano, o sistema coloca `ctrl.humanControl=true` e desliga Virtus (`virtus='off'` + `stopVirtus`).
- O Robe não enfileira para perfis em `humanControl` (guard no fluxo de fila global).
