## Hipóteses principais (a provar)

### H1) Sobrescrita por shard (cluster)

- Algum fluxo de escrita gravou `C:\conveniente\dados\perfis.json` usando um subconjunto “do shard” (ex.: 7 perfis) em vez do conjunto global.
- Este é um risco conhecido em ambientes sharded se algum caminho usar `loadPerfisJson()` (filtrado por shard) e depois `savePerfisJson()` para gravar o arquivo global.

### H2) Migração/cleanup indevido

- Algum comando (ex.: `profiles_cleanup`, `migrate_profiles`, `delete_perfis` indevido) limpou entradas ou reescreveu os JSON.

### H3) Corrupção/IO parcial (write não-atômico ou corrida)

- `perfis.json` foi truncado/corrompido por write concorrente/crash no meio do write, levando o sistema a “se recuperar” criando arquivo novo pequeno.
