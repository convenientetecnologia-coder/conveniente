# INC-20260413-1700-01 — Configuração por servidor no dashboard (capacidade + Robe) com sincronização CT

Status: `in_progress`  
Prioridade: `P0`  
Projeto: `conveniente` (+ integração `sitechatbot/CT`)

## Contexto

Cada host tem perfil operacional diferente. O pedido é tornar parâmetros críticos configuráveis no dashboard local do servidor, com aplicação atômica e reflexo no CT:

1. capacidade de contas por servidor (por 8GB e/ou teto absoluto);
2. janela global de operação do Robe (incluindo 24h);
3. faixa de horas de trabalho por conta (até 24h);
4. ritmo de classificados por hora.

## Objetivo

Definir contrato técnico ponta a ponta (UI dashboard -> API host -> persistência -> runtime -> status/report -> CT) sem codar nesta fase.

## Escopo de auditoria

- mapear onde os limites atuais estão hardcoded;
- identificar quais parâmetros já são env/config e quais não são;
- definir desenho de configuração por host com hot-apply seguro;
- definir como CT passa a consumir capacidade configurada (não só heurística por RAM).
